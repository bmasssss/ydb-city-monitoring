# Аналитическая платформа для мониторинга городской инфраструктуры на YDB

## Описание проекта
Система для сбора данных с IoT-датчиков в реальном времени и построения аналитических отчетов. Реализован классический сценарий HTAP (Hybrid Transactional/Analytical Processing) с использованием YDB.

## Стек технологий
- **База данных:** YDB (строковые и колоночные таблицы, CDC, Topics)
- **Языки:** Python 3, YQL
- **Инфраструктура:** Docker, Kubernetes (Minikube), Helm
- **Мониторинг:** Prometheus, Grafana
- **Визуализация:** Streamlit, Plotly

## Структура репозитория
- `stage1_basic/` — Подключение к YDB, создание таблицы `sensors`.
- `stage2_data/` — Генератор 1 млн записей и загрузка в строковую таблицу.
- `stage3_olap/` — Создание колоночной таблицы и дашборд на Streamlit.
- `stage4_streaming/` — Настройка CDC и сервис алертов.
- `stage5_prod/` — Манифесты для развертывания в Kubernetes и мониторинга.
